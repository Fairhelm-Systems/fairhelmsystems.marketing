# Security Policy

This repository builds Fairhelm Systems' public marketing site. It contains no customer data, credentials, or production secrets — deployment credentials are resolved at runtime via the active AWS CLI identity and AWS Secrets Manager, never committed to source.

## Reporting a vulnerability

If you find a security issue in this repository or on fairhelmsystems.com, please report it privately rather than opening a public issue:

- Email: hello@fairhelmsystems.com — include a description, steps to reproduce, and any relevant request/response details.

We will acknowledge your report and follow up once the issue is understood. Please give us a reasonable amount of time to address a finding before any public disclosure.

## Scope

This policy covers the code in this repository and the site it deploys. Fairhelm Systems' product, SquareCampus, is a separate codebase with its own security posture — see [squarecampus.com](https://squarecampus.com/) for its disclosure channel.
